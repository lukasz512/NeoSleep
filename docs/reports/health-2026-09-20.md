# Health Report — 2026-09-20

## Summary
- **[Security, High]** Public contact form logs full PII (name, phone, email, city, message) to plaintext console output with no retention/access control (`apps/api/src/routes/website-contact.ts:12`) — quick fix, real GDPR exposure.
- **[UX, High — functional bug]** `PresentationViewer.vue`'s `&--rotated` SCSS rule is parsed as plain CSS (no `lang="scss"` on the `<style>` block), so the tablet landscape-rotation transform for HCP presentations likely never applies — this is the rep app's core in-visit feature.
- **[Architecture, High — docs drift]** CLAUDE.md's Database section is significantly stale: wrong schema-naming scheme (`tenant_<slug>`/`tbl_*` vs actual `platform.*` + company-slug schemas), a documented composable (`useAppConfig.ts`) that doesn't exist, and ~20 real tenant tables missing from the documented list. A fresh session using CLAUDE.md as ground truth will get the DB model wrong.
- **[Test Coverage, High]** Three API routes (`lookup.ts`, `push.ts`, `invite.ts`) have zero test coverage of any kind — no 401-on-no-session test, violating QA's own mandatory pre-push checklist item.
- **[i18n, Medium]** Hardcoded Spanish UI strings bypass i18n in `OrthoApneaOrderWizard.vue` (`"Desconocido"`, `"Mínima"`, `"Registro"`) — violates CLAUDE.md's "English only in source, `$t()` for all copy" rule; otherwise i18n key parity across en/pl/mx is clean.
