# SPEC-0032: Backup & Recovery Policy

Status: Draft  
Owner: Neo Sleep Care  
Apps/Modules: bff, ops  
Milestone: Phase 2

## 1) Goal
Define backup strategy before moving beyond Notion so that we can recover from data loss or corruption.

## 2) Requirements
- Daily backup job
- Backup retention (30/90 days policy)
- Restore test procedure
- Secrets backup checklist

## 3) DoD
- Documented runbook
- Test restore performed once
- Recovery time objective defined

- Runbook: backup & restore
- Ops docs: retention policy, RTO
