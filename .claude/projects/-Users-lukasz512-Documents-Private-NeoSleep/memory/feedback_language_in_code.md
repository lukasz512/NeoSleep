Always write comments, inline docs, and any text inside code files in English — not Polish.

**Why:** User explicitly requested this. Polish is fine in chat, English in code.

**How to apply:** All comments in .ts, .vue, .css, .scss, .sh, .json, config files etc. must be in English. Only shell script user-facing echo messages (terminal output) may be in Polish if they're UI text for the developer, but inline code comments must be English.
