# Brand assets (website)

**Jedno miejsce** na assety brandu w aplikacji website.

- **logos/** – pliki SVG (icon_light, icon_dark, logo_light, logo_dark). Źródło: repo root `brand/logos/` – skopiuj lub zsymlinkuj przy aktualizacji.
- **Kolory** – paleta w `src/config/brandColors.ts`, zmienne CSS w `src/assets/website-theme.scss`. Zob. też `foundation/docs/BRAND_AND_APP_CONFIG.md`.

Odwołania w kodzie: `/brand/logos/nazwa.svg` (Vite serwuje z `public/`).
